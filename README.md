# 📧 Auto Email Response Generator

A Streamlit app powered by GPT-4 that generates professional, friendly, or persuasive email replies automatically.

## 🚀 Features
- Paste received email
- Choose tone for reply
- Get a natural, context-aware response

## 🛠 Setup
1. `git clone https://github.com/yourusername/auto_email_agent`
2. Add your OpenAI API key in `email_agent.py`
3. `pip install -r requirements.txt`
4. `streamlit run main.py`
